Internal Data sources: 
* Can be
	* Host
	* Network
	* Finished intel
* Endpoint Data:
	* Process execution
	* Registry access data
	* File Data
	* Network Data
* Network Data:
	* Network devices
	* Security Devices
	* Example: Firewall, Cloud, IDS, proxy, DNS
* Usualmente la red interna da mejor inteligencia que las fuentes externas. 
---
External Data sources:
* Can be
	* IOCS
	* Malware analysis results
	* Social media feeds
	* YARA rules
	* IDS rules
	* Dumps
	* Security blogs and reports. 
* Formatos: STIX, CSV, JSON, XML, PDF
* Se debe priorizar la inteligencia que presenta mayor amenaza para nuestra infra. Priorizar APT que me pueden atacar versus las que son trendy
