Unidad estadística: Análisis realizado en base a observaciones o valores observados. 
Población: Conjunto de unidades de estudio . El total de las unidades de estudio.

El valor de estudio de una unidad estadistica sería 1 elemento de una población. Una población es un conjunto de valores de unidades estadisticas. 

Ejemplo; si se está estudiando el ingreso mensual de un Ing de la zona franca AFZ. La población sería cada ingreso mensual obtenido, y no los ingenieros como tal. Los ingenieros serían la unidad estadistica. 

Una población puede ser infinita o finita. La población es finita cuando se está analizando un momento dado, mientas que si la situación de estudio planteada aplica para cualquier momento dado, aunque la muestra sea X número, la población es infinita, ya que aplica para cualquier grupo en cualquier momento dado.

Si el proceso puede repetirse de forma infinita, la población es infinita. 


Un solo conjunto de unidades estadisticas puede dar vida a diferentes poblaciones. 

Muestreo: Se refiere a la practica de tomar solamente un número finito de unidades para el estudio y luego que estas generalidades obtenidas apliquen para un número más grande de unidades. Se toma una muestra y luego se generaliza. 
La selección para el muestreo suele estar sesgado, por lo tanto los resultados o conclusiones pueden ser erroneas o que no aplican. Por lo cual, siempre se recomienda que la selección de la población para el muestreo sea aleatoria. 

---
Selección de muestra
- Al azar
- Intencional: Se usa la experiencia y conocimiento para la selección
- Por conveniencia: los que sean de más fácil acceso
el método aleatorio ayuda a eliminar los sesgos de selección, por lo cual los resultados se pueden generalizar más. 

Tabla de número al azar: es una tabla que los estadisticos utilizan para garantizar la aleteoridad al momento de hacer la selección de las unidades estadisticas. 

Atributos y variables
Cuando se realiza un análisis estadístico se mide y se cuenta. Cuando algo no se puede medir o contar, se categoriza. El libro da el ejemplo del estado civil. no se puede medir ni contar, pero si se puede categorizar y luego contar estas categorizaciones. 

Se denomina variable a las caracteristicas que se miden o cuentan de una unidad estadistica. Debido a que son valores VARIABLES de una unidad a otra. 
Tipos de variables:
- Cuantitativas: medibles, peso, edad, número de hijos, ingreso mensual
	- Continua: Un valor de un intervalo de numeros reales. Es cuando ese valor puede ser cualquiera dentro de un intervalo de números. Edad o peso, velocidad
	- Discreta: valores numerables. Solamente puede tomar un número determinado de valores. Ejemplo, no se puede meter un gol y medio. No puede ser un valor fraccionario. Son valores fijos donde solo se puede tomar uno de ellos.
- Cualitativas: ej estado civil. Una cualidad. Un tipo o categoría de algo. 

Estadistica Descriptiva: Descripción del conjunto de datos observador. El mayor interes es describir un grupo de datos. El uso de gráficos, curadros, promedios, porcentajes y medidas son un ejemplo de estadistica descriptiva. 
Estadistica inferencial: Obtener conclusiones para el grupo observado. O sea obtener conclusiones que se aplica a grupos de datos más amplios que los analizados. 

Para utilizar la estadistica inferencial se deben resolver 2 problemas. El tamaño de la muestra y el método para seleccionar la muestra.  Cuando la muestra es aleatoria se puede medir el error de muestreo, mientras que si es de juicio o conveniencia, no se puede calcular el error de muestreo, por lo cual los datos no se pueden generalizar de la misma manera. 

Estadisticas: conjunto de datos numéricos que han sido organizados, resumidos y presentados para demostrar un fenómeno. 

Estadistica: Es el término que se aplica para definir la ciencia/disciplina que se encarga de estudiar los métodos de recolección, análisis, presentación, interpretación y clasificación.

Estadisiticas son los datos ya procesados, la estadisitica es la disciplina que se utiliza para crear estadisticas.
